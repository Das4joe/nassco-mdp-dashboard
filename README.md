# nassco-mdp-dashboard-netlify

NASSCO MDP Dashboard project

This repository contains the Netlify deployment version of the NASSCO MDP Dashboard, built with React + TypeScript + Vite.

## Features

- React + TypeScript + Vite setup
- Tailwind CSS integration
- ESLint configuration for type-aware linting
- GeoJSON and CSV data handling for visualization

## Deployment

- Vercel deployment: [nassco-mdp-dashboard](https://nassco-mdp-dashboard.vercel.app)
- Netlify deployment: [nassco-mdp-dashboard-netlify](https://nassco-mdp-dashboard.netlify.app)
